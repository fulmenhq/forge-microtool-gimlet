# Gimlet Release v0.2.0 (2026-10-11)

## Summary

Toolchain and dependency refresh for the public template baseline. Earlier tags are not included in the initial commit.

## Highlights

- Go `1.26.9`. `gofulmen` `v0.3.6`, `crucible` `v0.4.19`.
- CI and release run on digest-pinned `goneat-tools-runner-glibc` `v0.5.8`. The goneat bootstrap pin is `v0.6.2`. The image is the toolchain.
- Workflow actions are SHA-pinned. CI permissions are `contents: read`.
- Release archives: linux/amd64, linux/arm64, darwin/arm64, windows/amd64. darwin/amd64 is not published. Intel Macs build from source: `GOOS=darwin GOARCH=amd64 go build ./cmd/gimlet`.
- This template does not include a signed-tag release ceremony, a committed public-key pin, or a GitHub "Verified" tag gate. `make package-sign` can still detach-sign `SHA256SUMS` with your own key. See the CDRL guide for a public pattern reference.
- Trademark notice in `LICENSE`: 3 Leaps, LLC, a North Carolina LLC.

## Notes for template consumers

`CHANGELOG.md`, `RELEASE_NOTES.md`, and `docs/releases/` describe this template. During CDRL, delete them or rewrite them for your project.
